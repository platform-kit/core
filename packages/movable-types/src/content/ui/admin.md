The words of the admin's own chrome: the rail's groups and the name of every page in it. They
were literals in AdminPage.vue, which meant the one surface a shop's team lives in was the one
surface they could not reword.

A page whose own strings file already names it — People, Payouts, Media, Publishing — keeps that
name and is not repeated here: one name, one place.
