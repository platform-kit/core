# Comments

The words of the one page responsible for every comment on the site, and of the reader's own
thread. A site overrides any of them by key in content/app/ui/comments.md.

## admin

### head

title: Comments
subtitle: Review and moderate comments.
count: {n} shown, {waiting} waiting
loading: Reading…
empty: Nothing here.
denied: This account cannot moderate comments.
error: The comments could not be read. Try again.
someone: Someone

### filters

state: Showing
state-waiting: Waiting for a decision
state-live: Published
state-removed: Removed
state-all: Everything
where: Where
where-all: Everywhere
where-rooms: In a forum room
where-pages: On a page only
kind: Kind
kind-all: Anything

### row

under: under
in-room: also a post in the community
trusted: known

removed: This comment was removed.
approve: Publish it
refuse: Refuse it
remove: Remove it
reply: Reply
placeholder: Answer {name}…
send: Send
