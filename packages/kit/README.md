# @platform-kit/kit

PlatformKit's core: everything a publishing site needs that has no pixels — the content pipeline, the Vite plugin, the data layer (migrations, functions, the seed's shape), the ledger and the offers, the chats, the funnels, the emails, the instrument's mechanics, the enrichment, spoken books, print production, the deploy and its checks, the CLI.

A site is a `platformkit.config.js`, a `content/` folder and a theme (`@platform-kit/movable-types` is the default). `npx platformkit dev` serves it; `npx platformkit help` lists the rest.
